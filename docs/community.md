# Community

Ambar OS is open source (Apache-2.0) and built in the open on [GitHub](https://github.com/alexbieber/AmbarOS).

## Get help

1. Look in [Troubleshooting](troubleshooting.md) and the [FAQ](faq.md).
2. Search [existing issues](https://github.com/alexbieber/AmbarOS/issues?q=is%3Aissue). Someone may already have the answer.
3. Ask in [Discussions](https://github.com/alexbieber/AmbarOS/discussions) for questions, ideas and "how do I…".
4. Open a [bug report](https://github.com/alexbieber/AmbarOS/issues/new?template=bug_report.yml) for something that's broken. Include the output from [Collect information for a bug report](troubleshooting.md#collect-information-for-a-bug-report).

## Help out, no coding needed

- **Hardware reports.** This is the most useful thing right now. Try the [live USB](live-usb.md) and [send a report](hardware.md#report-your-computer).
- **Docs.** If something here was unclear or wrong, use the edit link at the top of the page or open an issue.
- **Automations.** Share useful automations as [packages](developer-guide.md#packages).

## Contribute code

Read [CONTRIBUTING.md](https://github.com/alexbieber/AmbarOS/blob/main/CONTRIBUTING.md). In short:

```sh
bash scripts/verify.sh      # everything CI runs, plus a live service test
```

Every change needs tests, and nothing is described as working unless a test shows it.

## Security issues

Don't open a public issue. Report privately through [GitHub security advisories](https://github.com/alexbieber/AmbarOS/security/advisories/new). See [SECURITY.md](https://github.com/alexbieber/AmbarOS/blob/main/SECURITY.md).

## Code of conduct

Be kind, be patient, assume good intent. The full [Code of Conduct](https://github.com/alexbieber/AmbarOS/blob/main/CODE_OF_CONDUCT.md) applies everywhere in the project.
